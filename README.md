# DualCam iOS

Native Swift/SwiftUI iPhone dual-camera project based on the supplied requirements.

## Project archive
Download `DualCam-iOS.zip` from this repository, extract it, and open `DualCam.xcodeproj` in Xcode on macOS.

## Status
This is an initial development scaffold. It has not been compiled with Xcode or tested on a physical iPhone in this environment. Some features in the original requirements remain incomplete; see the included README for the detailed status and limitations.

## Requirements
- iOS 17+
- Xcode 16+
- A physical iPhone supporting `AVCaptureMultiCamSession` for dual-camera testing

## Signing
Set your own Team and Bundle Identifier in Xcode before running.
